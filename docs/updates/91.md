# PR 91: Globally managed Cua skills and typed failures

## Intent of the change

- Stop attaching Tilde's canonical Cua skill to every agent after it became globally managed.
- Return typed Cua driver failures through the normal tool-result contract instead of letting them escape as transport failures.

## Architecture changes

- Agent Provider keeps the OpenBot computer-use overlay and user-owned skills while removing legacy explicit canonical Cua membership.
- Reconciliation no longer queries managed skill providers or adds the canonical provider skill to individual registries.
- Computer service maps `DriverError.Tool` messages and error codes into failed, not-started Cua results.
- ADR-0029 records global ownership of the canonical package.

Validation completed:

- Computer-service Cua tests: 8 passed.
- Agent Provider skill reconciliation tests: 2 passed.
- `pnpm check`: passed with existing repository warnings only.
- `pnpm build`: passed, including package verification, CLI verification, and Android/iOS Expo exports.
