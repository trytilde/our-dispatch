# PR 90: Bound default agent tool loops

## Intent of the change

- Give substantial tool workflows more room than the previous 12-step default.
- Keep the upstream default bounded so faulty or cyclic model/tool runs cannot continue indefinitely.

## Architecture changes

- The provider-owned Vercel inference template now stops at 50 steps.
- Initialization migration tests verify both existing and future generated agent files receive the bound.
- Fork-owned authored agents and `configuration/` remain outside this contribution.
- ADR-0011 records the default and confirms forks may override copied authored code.

Validation completed:

- CLI initialization tests: 20 passed.
- Inference Provider tests: 12 passed.
- `pnpm check`: passed with existing repository warnings only.
- `pnpm build`: passed, including package verification, CLI verification, and Android/iOS Expo exports.

## Critical to apply to forks

no

Existing authored-agent files change only through the normal explicit inference-template migration. Forks with their own bound may retain it.
